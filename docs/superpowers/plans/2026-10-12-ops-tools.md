# Ops Tools (Step 6c) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cho người vận hành (role OPS) bốn công cụ trong wallet — đóng/mở băng ví, điều chỉnh số dư, đảo giao dịch, phát lại `OrderPaidV1` — với nhật ký kiểm toán chung `ops_actions`, API `/ops/...`, idempotency và quan sát tối thiểu.

**Architecture:** Mọi thay đổi nằm trong service `wallet` (payment không đổi) cộng một giá trị enum trong `@billing/contracts`. Domain thêm trạng thái đóng băng cho `Account`, loại tài khoản `ADJUSTMENT` và hai loại giao dịch `ADJUSTMENT`/`REVERSAL`. Application thêm helper `OpsActionRecorder` (idempotency + audit trong cùng transaction) và bốn use case; `PayOrder` từ chối khi ví đóng băng và ghi nhớ `paid_event_id`. Interface thêm `OpsGuard` (header do gateway đặt) và `OpsController`. Migration tenant `007-ops-tools`.

**Tech Stack:** TypeScript, NestJS + Fastify (wallet), Kysely + SQL Server (schema `t_<tenant>`), vitest, OpenTelemetry (adapter metric), `corepack pnpm`.

Freeze ví đã đóng băng / unfreeze ví đang mở → 200 `changed:false`, không ghi `ops_actions`.
- Mã lỗi HTTP: ví không có → 404 `WALLET_NOT_FOUND`; giao dịch không có → 404 `TRANSACTION_NOT_FOUND`; order chưa trả → 404 `ORDER_NOT_FOUND`; `DEBIT`/đảo làm ví âm → 409 `INSUFFICIENT_FUNDS`; đảo làm MERCHANT âm → 409 `REVERSAL_NOT_POSSIBLE`; giao dịch gốc là `TOPUP`/`REVERSAL` → 409 `REVERSAL_NOT_SUPPORTED`; đã đảo → 409 `ALREADY_REVERSED`; order đã đảo → 409 `ORDER_REVERSED`; `paid_event_id` null → 409 `EVENT_ID_UNKNOWN`; sai đồng tiền so với ví → 422 `INVALID_OPS_REQUEST`.
- Điều chỉnh: giao dịch `ADJUSTMENT` hai dòng giữa ví và `system:ADJUSTMENT:<cur>`; `CREDIT` cộng ví, `DEBIT` trừ ví; `business_key = adjustment:<actionId>`. Đảo: giao dịch `REVERSAL` đối nghịch từng dòng, `business_key = reversal:<originalId>`, `reverses_transaction_id = originalId`; chỉ cho gốc là `ORDER_PAYMENT` hoặc `ADJUSTMENT`. Sổ cái chỉ thêm, không sửa/xóa dòng cũ; dòng `order_payments` của order bị đảo giữ nguyên.
- Đóng băng chỉ chặn ghi nợ ví khi trả order: nhánh từ chối `WALLET_FROZEN` (vẫn commit inbox + outbox `OrderPaymentFailedV1`). Nạp tiền, điều chỉnh, đảo vẫn chạy trên ví đóng băng. Chỉ tài khoản `WALLET` được đóng băng.
- Phát lại: ghi dòng outbox mới có `outbox.id` mới, payload `eventId = order_payments.paid_event_id` (giữ nguyên), `occurredAtUtc = paidAtUtc = paid_at`, `correlationId = ops-replay:<actionId>`; không tạo giao dịch sổ cái; trả 202 `{eventId, actionId}`.

```ts
/** Điều chỉnh có đối ứng: CREDIT cộng ví, DEBIT trừ ví; đối ứng là tài khoản ADJUSTMENT cùng đồng tiền. */
static adjustment(input: {
  id: string; actionId: string; walletAccountId: string; adjustmentAccountId: string;
  direction: 'CREDIT' | 'DEBIT'; amount: Money; now: Date;
}): LedgerTransaction {
  if (!input.amount.isPositive()) {
    throw new InvalidLedgerTransactionError('an adjustment amount must be positive');
  }
  const walletDelta = input.direction === 'CREDIT' ? input.amount : input.amount.negate();
  return LedgerTransaction.create({
    id: input.id,
    businessKey: `adjustment:${input.actionId}`,
    kind: 'ADJUSTMENT',
    entries: [
      { accountId: input.walletAccountId, amount: walletDelta },
      { accountId: input.adjustmentAccountId, amount: walletDelta.negate() },
    ],
    now: input.now,
  });
}

/** Đảo một giao dịch: mỗi dòng đổi dấu; chỉ thêm giao dịch mới, không sửa giao dịch gốc. */
static reversal(input: {
  id: string; original: { id: string; entries: readonly LedgerEntry[] }; now: Date;
}): LedgerTransaction {
  return LedgerTransaction.create({
    id: input.id,
    businessKey: `reversal:${input.original.id}`,
    kind: 'REVERSAL',
    entries: input.original.entries.map((e) => ({ accountId: e.accountId, amount: e.amount.negate() })),
    reverses: input.original.id,
    now: input.now,
  });
}
```

```ts
        const done = await input.work({ repositories, actionId, now });
        if (done.record) {

            target: input.target, idempotencyKey: request.idempotencyKey, fingerprint, result: JSON.stringify(done.result), createdAt: now });
        }
        return { result: done.result, replayed: false, recorded: done.record };

      this.deps.metrics.opsAction(input.tenant.value, input.action, outcome.recorded ? 'ok' : 'noop');
      if (outcome.recorded) this.deps.log.info({ tenantId: input.tenant.value, action: input.action, actor: request.actor, target: input.target }, 'ops action recorded');
```
